# Charter Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Browse Charts: a catalogue of chart and diagram types grouped by family, as a grid of thumbnails or a list with a detail panel
- Each type shows whether Mermaid, shadcn or ECharts can draw it, with the Mermaid release that added the type
- A provider filter in the search bar, favourites pinned to the top, and a Recent section for the last five types used
- Copy the docs link, the template in a Mermaid fence or raw, a prompt snippet or the shadcn install command from any type
- Render Chart: draw a Mermaid diagram or an ECharts option from the selection, the clipboard or a pasted source, then copy, save or open the picture
- Render Template draws any catalogue type's Mermaid example
